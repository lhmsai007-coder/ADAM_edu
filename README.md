# ADAM-Edu

Interactive teaching materials for animal breeding and quantitative genetics.

[Open the workshop website](https://lhmsai007.shinyapps.io/ADAM-Edu-current/workshop/index.html)

Participants need a computer, modern web browser and internet access. No software installation, programming or account is required.

## Applications
- [Historical population and LD](https://lhmsai007.shinyapps.io/ADAM-Edu-history/)
- [Base population](https://lhmsai007.shinyapps.io/ADAM-Edu-base/)
- [Current population and breeding programmes](https://lhmsai007.shinyapps.io/ADAM-Edu-current/)

This public repository contains only the rendered workshop website, participant manual and practical, and approved simulated example populations. Application source, credentials and instructor materials are excluded.

The simulations illustrate biological mechanisms in simplified populations, rather than calibrated forecasts for a particular livestock population.
