# ADAM-Edu

ADAM-Edu is an interactive teaching tool for animal breeding and quantitative genetics. Workshop participants use a web browser and internet connection; no installation or account is required.

## Online applications

- [Historical population and LD](https://lhmsai007.shinyapps.io/ADAM-Edu-history/)
- [Base population](https://lhmsai007.shinyapps.io/ADAM-Edu-base/)
- [Current population and breeding programmes](https://lhmsai007.shinyapps.io/ADAM-Edu-current/)

This repository is reserved for the public workshop website, participant PDFs and simulated example populations. Application source and instructor materials are maintained separately and are not included here.

The simulations illustrate stochastic inheritance, prediction, selection and diversity in simplified populations. They are teaching examples, not calibrated livestock forecasts.
